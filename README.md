# PokePrisma

Juego web de colección de cartas Pokémon y combates por turnos para móvil y ordenador.

Repositorio: https://github.com/CACHUMBAS/Proyecto-Pokemon

## Estado

Planificación inicial. Este repositorio contiene documentación; todavía no hay aplicación, dependencias instaladas ni servicios externos creados.

## Documentos de trabajo

- [Diseño del juego](docs/superpowers/specs/2026-10-08-pokeprisma-design.md): alcance acordado, pantallas, reglas propuestas, datos y arquitectura.
- [Plan de la primera fase](docs/superpowers/plans/2026-10-08-pokeprisma-fase-1.md): tareas verificables para construir la base visual y técnica.

## Decisiones acordadas

- Web en español e inglés, adaptada a móvil y ordenador.
- Estética de Pokédex tecnológica y cartas holográficas.
- Cuenta obligatoria, mediante Google o correo y contraseña.
- Todas las generaciones; catálogo basado en PokéAPI y TCGdex.
- Sobres adquiridos con monedas obtenidas al ganar o con fragmentos de duplicados.
- Variantes con estadísticas diferentes y mayor poder para las rarezas superiores.
- Equipos de seis Pokémon y hasta tres apoyos de Entrenador o Energía.
- Tutorial, partidas rápidas y campaña contra la máquina; salas privadas entre jugadores.
- Tipos, debilidades, resistencias, inmunidades y estados alterados.
- Turnos de 45 segundos y margen de reconexión de 60 segundos.
- Música, efectos y sonidos de Pokémon, con controles de volumen.
- Presupuesto inicial de cero euros y sin fecha de entrega fijada.

## Forma de trabajo

Cada fase tendrá su rama, comprobaciones y commits descriptivos. VS Code será el editor visible del proyecto. Las credenciales y la configuración local de servicios no se subirán a Git.

La primera fase no incluye publicar un juego terminado. Cuentas, economía y multijugador requieren las fases siguientes y pruebas propias. No se promete capacidad ilimitada en planes gratuitos.
